# Claude Code Extension Builder

**Version**: 2.4.0
**Last Updated**: 2026-02-04

## 목적

Claude Code 확장 기능(Skills, Agents, Hooks) 개발 질문 답변 및 구현 가이드 제공.

---

## 핵심 변경 사항 (v2.3.0+)

### 새로운 Hook 이벤트

| 신규 이벤트 | 용도 |
|------------|------|
| `SubagentStart` | 서브에이전트 생성 시점 |
| `PostToolUseFailure` | 도구 호출 실패 후 |
| `Setup` | 초기 설정 (--init, --init-only, --maintenance) |

### 새로운 Hook 타입

| Hook 타입 | 설명 |
|-----------|------|
| `type: "prompt"` | 프롬프트 기반 Hook (Claude가 처리) |
| `type: "agent"` | 에이전트 기반 Hook (전용 에이전트 실행) |
| `async: true` | 비동기 Hook (백그라운드 실행) |

### Skills 신규 옵션

| 옵션 | 설명 |
|------|------|
| `argument-hint` | 자동완성 시 힌트 표시 |
| `${CLAUDE_SESSION_ID}` | 세션 ID 문자열 치환 |
| Dynamic Context | `!` + backtick + `command` + backtick 문법으로 동적 컨텍스트 주입 |

### Subagents 신규 옵션

| 옵션 | 설명 |
|------|------|
| `disallowedTools` | 명시적 도구 차단 목록 |
| `permissionMode` | 권한 모드 (default, acceptEdits, dontAsk, bypassPermissions, plan) |
| `resume` | 에이전트 재개 기능 |
| Background Execution | `run_in_background: true`로 백그라운드 실행 |

## Deprecated (사용 중지)

| Deprecated | 대체 방법 |
|------------|-----------|
| `output styles` | `--system-prompt-file` 또는 `plugins` 사용 |
| `legacy SDK entrypoint` | `@anthropic-ai/claude-agent-sdk`로 마이그레이션 |
| `includeCoAuthoredBy` 설정 | 새 `attribution` 설정 사용 |

---

## 확장 기능 유형 요약

| 유형 | 용도 | 컨텍스트 | 위치 |
|------|------|----------|------|
| **Skill** | 지식/가이드 주입 + 슬래시 명령 | 현재 대화 (fork 시 별도) | `.claude/skills/` |
| **Subagent** | 독립 에이전트 정의 | 별도 200k | `.claude/agents/` |
| **Hook** | 워크플로우 제어 | - | `settings.json` |

## Quick Reference

### Skills 핵심

```yaml
---
name: my-skill
description: "설명 + 자동 활성화 키워드"
userInvocable: true
argument-hint: "<topic>"
allowed-tools: [Read, Grep, Glob]
---

# My Skill

## 목적
스킬의 목적

## 지침
상세 내용은 references/ 참조
```

**상세**: [references/skills-guide.md](references/skills-guide.md)

---

### Hooks 핵심

```json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash|Write",
      "hooks": [{
        "type": "command",
        "command": "./hooks/validate.sh"
      }]
    }],
    "Stop": [{
      "type": "command",
      "command": "./hooks/on-stop.sh"
    }]
  }
}
```

**주요 이벤트**: SessionStart, PreToolUse, PostToolUse, Stop, SubagentStop

**상세**: [references/hooks-guide.md](references/hooks-guide.md)

---

### Subagents 핵심

```yaml
---
name: frontend-developer
description: "React/Next.js 개발 전문"
model: sonnet
allowed-tools: [Read, Write, Edit, Bash(npm:*)]
permissionMode: acceptEdits
---

# Frontend Developer Agent
```

**내장 타입**: Explore, Plan, general-purpose, Bash, claude-code-guide

**상세**: [references/subagents-guide.md](references/subagents-guide.md)

## 사용 시나리오 결정 가이드

```
Q: 반복적으로 같은 지침이 필요한가?
├─ Yes → Skill 생성
└─ No
   Q: 독립적인 작업 실행이 필요한가?
   ├─ Yes → Task Tool 사용
   │  Q: 커스텀 에이전트가 필요한가?
   │  ├─ Yes → Subagent 정의 후 Task에서 호출
   │  └─ No → 내장 subagent_type 사용 (Explore, Plan, general-purpose)
   └─ No → 직접 대화에서 처리
```

## Progressive Disclosure (500줄 규칙)

SKILL.md는 500줄 이하로 유지합니다:

```
my-skill/
├── SKILL.md          # < 500줄 (개요만)
├── CHANGELOG.md      # 변경 이력
├── releases/         # 버전별 스냅샷
└── references/       # 상세 가이드
    ├── topic-1.md
    └── topic-2.md
```
